# Financial Tools — published site

The live site: **https://thomasmorrierbompoint.github.io/financial-tools-public/**

A small, fast website of financial tools built to teach intuition, in French or English, for a
Canadian audience. Entirely client-side: Vue 3 + PrimeVue 5 from CDN, no build step, no account,
no tracking, nothing sent anywhere — every calculation runs in the browser.

## This repository is generated

Everything here is published automatically from a private source repository whenever its `main`
branch moves. **Do not edit these files directly** — the next publish overwrites them, and the
repository's history is one commit per release, not the real development history.

Spotted a bug or a wrong number? Open an issue here; that is the right place for it. Pull requests
against this repository cannot be merged, because the change would be erased by the next publish.
